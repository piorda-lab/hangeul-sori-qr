# 한글 소리 QR

자음 14개와 기본 모음 10개, 총 24개 자모의 개별 QR 학습 페이지입니다.

## 현재 포함된 기능
- 자음 14개 / 기본 모음 10개 카드
- 자모별 QR 코드 자동 생성
- QR 스캔 시 해당 자모 전용 학습 화면 표시
- 브라우저의 한국어 음성 합성 기능으로 이름과 예시 발음 재생
- QR 개별 PNG 저장 및 전체 카드 인쇄
- 자음은 이름(예: 기역)과 예시 음절(가, 고, 구)을 구분해 안내

## GitHub Pages 공개 방법
1. GitHub 계정에 로그인하고 새 Public repository를 만듭니다. 예: `hangeul-sori-qr`
2. 이 폴더 안의 `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, folder는 `/ (root)`로 선택하고 Save를 누릅니다.
6. 몇 분 후 `https://깃허브아이디.github.io/hangeul-sori-qr/` 형태의 주소가 생성됩니다.
7. 생성된 주소로 사이트에 접속하면 QR 코드가 해당 주소를 기준으로 만들어집니다.
8. QR을 인쇄하기 전에 실제 휴대전화로 자음과 모음 QR을 각각 테스트합니다.

## QR 코드 저장
웹페이지에서 **QR 저장**을 누르면 각 자모의 QR PNG를 저장할 수 있습니다. `QR 카드 인쇄`는 브라우저 인쇄 기능을 엽니다.

## 음성 안내 관련 참고
이 초기 버전은 별도 녹음 파일이 아니라 브라우저/기기의 Web Speech 음성 합성을 사용합니다. 기기와 브라우저에 따라 음색과 발음이 달라질 수 있으며, 일부 모바일 브라우저는 자동 재생을 제한하므로 사용자가 발음 버튼을 눌러야 합니다. 실제 발음 교육용 배포 전에는 한국어 원어민 녹음 파일로 교체하고 검수하는 것을 권장합니다.

자음은 단독으로 발음하기 어려운 경우가 있어 '기역' 같은 자모 이름과 '가, 고, 구' 같은 예시 음절을 함께 들려주도록 구성했습니다. 특히 ㅇ은 음절 첫머리에서 소리가 없고 받침에서 소리가 난다는 설명을 포함했습니다.
